```text
STATUS: ████████████████████ COMPLETED
```

* Identificação de itens vencidos

# 🚚 `> Frete Flow`

```text
STATUS: █████████████░░░░░░░ IN DEVELOPMENT
```

**Frete Flow** é o projeto atual em desenvolvimento, criado a partir de uma **necessidade real de gestão e automação de fretes**.

A proposta é transformar um processo atualmente realizado de forma manual em uma solução backend estruturada, permitindo centralizar informações de **veículos, motoristas e fretes**, além de preparar a aplicação para futuras integrações e automações.

### 🎯 Objetivo

Construir uma aplicação capaz de organizar todo o fluxo de registro e gerenciamento de fretes, criando uma base sólida para futuras integrações com ferramentas externas.

### 🧩 Domínio inicial
